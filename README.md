# Домашнее задание: WebDriver

Автотесты страницы [https://otus.home.kartushin.su/training.html](https://otus.home.kartushin.su/training.html).
Каждый сценарий открывает Google Chrome со своей опцией запуска и проверяет элемент страницы.

## Сценарии

1. **Headless** (`--headless=new`). В поле ввода вводится `ОТУС`, затем проверяется, что значение поля совпадает с введённым текстом.
2. **Киоск** (`--kiosk`). Нажимается «Открыть модальное окно», затем проверяется, что модальное окно стало видимым.
3. **Полный экран** (`--start-fullscreen`). В форму вводятся имя `фыв` и почта `asdf@sdfg.rt`, нажимается «Отправить». В блоке динамического сообщения на зелёном фоне ожидается текст `Форма отправлена с именем: фыв и email: asdf@sdfg.rt`.

## Требования

- JDK 21
- Maven 3.8+
- Google Chrome

Драйвер Chrome подбирает Selenium Manager, отдельно ставить ChromeDriver не нужно.

Режимы киоска и полного экрана открывают обычное окно, поэтому им нужен графический дисплей. Headless работает без него. На Linux без рабочего стола тесты можно запустить так:

```bash
xvfb-run -a mvn test
```

## Запуск

```bash
mvn test
```

Если стенд отвечает `502 Bad Gateway`, сценарий останавливается с этой ошибкой: страница в этот момент недоступна.

## Структура

- `driver/ChromeDriverFactory` — опции Chrome для трёх режимов
- `pages/TrainingPage` — действия и проверки на странице тренажёра
- `ChromeModesTest` — три сценария из задания
